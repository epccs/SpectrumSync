# SpectrumSync — GitHub repo (from epccs)

This repo's name https://github.com/epccs/SpectrumSync. It is a public-facing page that is a mixture of software and hardware projects.

## Files

- `README.md` — the landing page, describes the folder structure and naming
- `docs/` — system-level documentation: wiring diagrams and guides
- `hardware/` — PCB designs (KiCad/Eagle), split into `drivers/`, `led-boards/`, `controllers/`
- `firmware/` — points to the external repos holding each board's firmware (firmware itself is not vendored here)
- `examples/` — demo projects and simulators (e.g., `RGB+W_API_simulator`, `512DMX_simulator`)

## Editing guidance

- Spelling and grammar need to support open hardware for a wide audience.
